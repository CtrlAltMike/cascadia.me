Corrections

If it’s wrong, it gets fixed.

Preparedness information has real consequences. A quiet edit isn’t enough when an error could change someone’s understanding or action.

The process

Report, check, correct, note.

Use the Feedback button on any page. Include the page address, the passage or feature, and the source you think we should check.

  1. We preserve the report.

    A correction request is recorded with the affected page and enough context to investigate it.

  2. We check the source that issued it.

    For safety, route, scientific, public-health, and program claims, we go back to the issuing authority or strongest available primary source.

  3. We correct the page itself.

    Material errors are fixed where readers encounter them. We don’t leave a known error in place just because an explanation exists somewhere else.

  4. We make the change visible.

    The page gets a new review date and a concise correction note when the error affected meaning, safety, attribution, coverage, or a reader’s likely action.

Public log

Material corrections.

No material corrections have been recorded since this policy was adopted on July 25, 2026.

Copy edits, broken-link repairs that don’t change the guidance, and formatting fixes may be made without a log entry. When in doubt, we’ll favor disclosure. Tiny type has caused enough trouble in the world already.
