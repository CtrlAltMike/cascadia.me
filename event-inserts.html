Printable event inserts

Ask the questions that change with the event.

Use one insert beside the common neighborhood packet. Start with the current official instruction, record observable facts, and stop collecting information that doesn't change a decision.

Open the common packetReview the post-event method

These sheets are not alerts, inspections, or permission to enter danger. Follow evacuation orders and current local instructions. Mark reports as firsthand or secondhand and add a time.
