Printable field packet

A neighborhood inventory people can actually use.

Use the first two sheets on a quiet day. Keep the last two blank until something happens. Paper isn't glamorous, but it doesn't ask for a password while the power is out.

Read the neighborhood guide Use the post-event method Add event-specific sheets

On a phone or small screen, swipe each table sideways to preview every column. Printing keeps each sheet on one page.

This page doesn't collect or save anything. Print it or copy the headings by hand. Participation should be voluntary, and private information should stay with the people who need it.

Keep the quiet-day list separate from the event board

The inventory may contain private opt-in details. The event board should show only what people need to coordinate current work. When the event is over, return controlled sheets to their keeper or destroy them safely.
